# Frozen Decisions

1. Local-first, single-user V0.
2. Python + FastAPI + Jinja/HTMX + SQLite.
3. GitHub is code/docs source of truth; imported corpora and candidate DB remain local/private.
4. Artifact/staging contracts separate ingestion from deterministic runner.
5. Question identity != occurrence != presentation.
6. Exam != exam form/booklet.
7. Official bank key != universal truth.
8. Atomic Tree is versioned; edital wording remains source-faithful and maps into it.
9. Question explanations/enrichment are on-demand.
10. py-fsrs is the later scheduler; no homegrown spaced-repetition algorithm.
11. No IRT/TRI until trustworthy calibration data exists.
12. Historical recurrence is a feature, never a certainty claim.
13. No proprietary scraping dependency in the core.
