# Learning Science Baseline

This file records the initial research baseline that motivated later Learning Intelligence. It is not a substitute for the source-grounded evidence registry that M005 will build.

## High-confidence starting points

### Retrieval / practice testing
Practice testing/retrieval is generally more effective for durable learning than passive rereading, especially when feedback is available.

### Distributed practice / spacing
Spacing study/retrieval across time supports durable retention. There is no single universal 24h/7d/30d schedule appropriate for all material/candidates.

### Successive relearning
Repeated retrieval to criterion across spaced sessions is a strong practical model for durable knowledge.

### Interleaving and discrimination
Interleaving can be useful where the learning target requires choosing between confusable problem types/concepts rather than repeating one procedure in blocks.

### Performance ≠ learning
Ease and immediate performance can mislead; desirable difficulty and delayed retention matter.

### Feedback
Retrieval benefits are strengthened by corrective feedback, especially when initial answers are wrong or uncertain.

### Calibration
Confidence and accuracy can diverge. Capturing confidence before feedback allows the system to measure miscalibration instead of asking retrospectively.

### Pretesting
Attempting a question before studying the material can benefit subsequent learning when followed by study/feedback; it is an intervention to test, not a universal rule.

### Answer changing
Research often finds that changing an answer is not inherently harmful and can improve scores. The system therefore tracks first/final answer empirically instead of teaching “never change your answer.”

## Initial reference corpus to formalize later

- Dunlosky et al. (2013) — learning-technique utility review;
- Roediger & Karpicke (2006) — testing effect;
- Cepeda et al. (2006 and related spacing work) — distributed practice;
- Rawson & Dunlosky — successive relearning;
- Bjork/Bjork — desirable difficulties, storage vs retrieval performance concepts;
- Learning Scientists — practical synthesis of retrieval, spacing, interleaving, elaboration, concrete examples and dual coding;
- Pooja Agarwal — retrieval-practice implementation/feedback.
