# Architecture Decision Records

ADRs preserve the rationale behind decisions that materially constrain future implementation. They are append-only historical records: a later ADR may supersede an earlier one, but do not rewrite the earlier reasoning.

Status vocabulary: `Accepted`, `Superseded`, `Proposed`, `Rejected`.
