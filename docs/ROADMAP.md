# Roadmap

The roadmap is intentionally vertical-slice oriented. A milestone advances only when the previous layer produces useful study evidence, not because a feature list is complete.

## M001 — Foundation: Corpus In → First Attempt Out
**Outcome:** real corpus enters; real candidate attempt exits.

- migration runner;
- structured JSON/CSV/XLSX ingestion;
- Quest API adapter;
- official VUNESP PDF + independent final-key path;
- source registry / rights / staging / quarantine;
- canonical identity / occurrence / caderno handling;
- local Mini-QC;
- time + confidence + score persistence;
- first basic topic diagnostic.

**Gate:** a clean end-to-end vertical slice works with real data and tests.

## M002 — Atomic Tree + Verticalized Syllabus
**Outcome:** system knows the target knowledge universe and breadth.

- source-faithful current edital ingestion;
- versioned Atomic Tree;
- syllabus→tree mapping;
- initial question classification;
- historical coverage map;
- new/core/tail evidence states.

## M003 — Candidate Intelligence
**Outcome:** system detects meaningful candidate gaps instead of reporting raw percentages.

- unseen vs repeated performance;
- coverage-aware evidence states;
- confident-wrong;
- time distributions;
- error taxonomy;
- first prioritized gap report.

## M004 — Question / Bank Intelligence
**Outcome:** historical corpus reveals reusable assessment patterns.

- exact cross-exam recurrence analytics;
- conservative near-duplicate detection;
- semantic question-family experiments;
- recurrence features;
- distractor/trap taxonomy experiments;
- Bank DNA baselines.

## M005 — Knowledge Pipeline
**Outcome:** one long practitioner/science source becomes a lossless, auditable learning canon.

- OQF neuroscience masterclass pilot;
- timestamped transcript + visual references;
- atoms/concepts/protocols;
- claims/evidence matrix;
- coverage audit;
- first Learning Canon slice.

## M006 — Learning + Memory
**Outcome:** candidate errors trigger appropriate interventions and durable review.

- inline error capture;
- Question Learning Packet depth rules;
- intervention library;
- memory items;
- py-fsrs integration;
- delayed retest/retention evidence;
- N-of-1 intervention logging.

## M007 — Decision Engine / Today
**Outcome:** system prescribes the next study actions with reasons.

- interpretable priority baseline;
- periodization phase;
- time allocation;
- due review/retest integration;
- Today queue;
- weekly recalibration;
- compare decision policy with simple baselines.

## Later only if evidence justifies
- richer adaptive testing;
- externally calibrated IRT/TRI;
- knowledge tracing;
- Monte Carlo approval/score simulations;
- DuckDB/Parquet analytics projection;
- multi-agent automation;
- multi-user/cloud productization.
