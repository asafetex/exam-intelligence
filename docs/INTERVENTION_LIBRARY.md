# Intervention Library

This document defines intervention **classes**. Exact protocols are populated by the Knowledge Pipeline and personal validation later.

## Core intervention families

### Concept acquisition
Use when the candidate lacks a coherent model.
- focused theory;
- worked examples;
- concrete examples;
- concept/relationship map;
- explanation/elaboration.

### Retrieval strengthening
Use when knowledge exists but recall is weak.
- free recall;
- practice testing;
- flashcard/memory item;
- successive relearning;
- delayed retest.

### Discrimination / confusion correction
Use when neighboring concepts are mixed.
- contrast table;
- interleaved similar problems;
- “why A not B?” prompts;
- targeted distractors.

### Application
Use when declarative knowledge does not transfer to questions.
- official questions;
- worked→faded examples;
- mixed problem sets;
- generated practice explicitly labeled synthetic.

### Bank-specific trap correction
Use when content is known but Assessment DNA defeats execution.
- distractor taxonomy drill;
- stem-operator drill;
- rule/exception contrast;
- time/wording constraints.

### Fluency / timing
Use when correctness is adequate but too slow.
- timed batches;
- pacing constraints;
- progressive time compression;
- exam simulations.

### Calibration
Use for confidence/decision mismatch.
- pre-feedback confidence capture;
- confident-wrong review;
- decision threshold practice for penalized scoring.

### Retention recovery
Use when delayed evidence decays.
- spaced retrieval;
- relearning;
- memory item + later official-question validation.

## Selection rule

Do not prescribe an intervention solely because it is popular. Selection must connect:

```text
diagnosis → intervention rationale → protocol → measurement → delayed outcome
```
